# Nintendont 960i - video experiments
#
# Copy this file to the ROOT of the drive Nintendont boots from.
# Each "name=value" line (decimal) changes one setting. Lines starting
# with # are ignored. Delete or rename this file for normal 960i.
# nin960i.log lists every setting that was applied and the frame length.
#
# Enable ONE experiment at a time by removing the # from its lines.
#
# ---------------------------------------------------------------------
# Swiss settings
#   gamevmode     Swiss "Video Mode": 1=480i 2=480sf 3=240p 4=960i 5=480p
#   forcevjitter  Swiss "Force Field Rendering": 1=On 2=Off 3=TAA
#   forcevfilter  Swiss "Force Vertical Filter": 1, 2 or 3
#   avecompat     Swiss "AVE Compatibility": 2=CMPV-DOL 4=GCVideo 5=AVE-RVL
#
# 960i timing table fields (only used in 960i mode)
#   equ acv prbodd prbeven psbodd psbeven bs1-bs4 be1-be4 nhlines hlw
#   hsy hcs hce hbe640 hbs640
# Swiss's 960i: equ=12 acv=480 prbodd=48 prbeven=49 psbodd=5 psbeven=4
#   bs 24/25/24/25 be 1038/1037/1038/1037 nhlines=1049 hlw=429
# Frame length in half-lines = 3*equ + prb + 2*acv + psb
# ---------------------------------------------------------------------
#
# Results so far (Kirby Air Ride, component, test monitor):
#   default 960i ........ rolls up slowly, locks briefly
#   A (1050) ............ no difference
#   B (1052) ............ locks more often, still rolls up at the same rate
#   C (1051) ............ no difference
