# Nintendont 960i - video experiments
#
# Copy this file to the ROOT of the drive Nintendont boots from.
# Each "name=value" line (decimal) changes one setting. Lines starting
# with # are ignored. Delete or rename this file for normal 960i.
# nin960i.log lists every setting that was applied and the frame length.
#
# Enable ONE experiment at a time by removing the # from its lines.
# The "960i Field Render" setting must be ON or this file is ignored.
#
# ---------------------------------------------------------------------
# Swiss settings
#   swiss         0 = don't apply the Swiss video patches (baseline)
#   gamevmode     Swiss "Video Mode": 1=480i 2=480sf 3=240p 4=960i 5=480p
#   forcevjitter  Swiss "Force Field Rendering": 1=On 2=Off 3=TAA
#   forcevfilter  Swiss "Force Vertical Filter": 1, 2 or 3
#   avecompat     Swiss "AVE Compatibility": 2=CMPV-DOL 4=GCVideo 5=AVE-RVL
#
# 960i timing table fields (only used in 960i mode)
#   equ acv prbodd prbeven psbodd psbeven bs1-bs4 be1-be4 nhlines hlw
#   hsy hcs hce hbe640 hbs640
# Swiss's 960i: equ=12 acv=480 prbodd=48 prbeven=49 psbodd=5 psbeven=4
#   bs 24/25/24/25 be 1038/1037/1038/1037 nhlines=1049 hlw=429
# Frame length in half-lines = 3*equ + prb + 2*acv + psb
# ---------------------------------------------------------------------
#
# =====================================================================
# 1280x240p experiment (Swiss Video page: "1280x240p (exp.)" = Left half)
# These use the hr_ prefix and only change the 1280x240p timing.
# Default: equ=6 acv=240 prbodd/even=24 psbodd/even=4 nhlines=526
#   hlw=858 hsy=127 hbe640=255 hbs640=677 (picture clocks 295-1575)
# Tip: put 00=01 in nin960i_ave.txt too. Its color bars come from the
# encoder itself, so they show whether the encoder outputs a picture
# at all, whatever the game draws.
# Enable ONE of R1-R3 at a time.
#
# --- T1: Two-pass test - replay each frame UNCHANGED (no right half)
# Hangs too -> replaying the frame itself is the problem.
# Works (left half picture, game runs) -> the right half changes are.
#hrtest=1
#
# --- T6: right half replay, but the copy still goes to the left half
# (scissor + viewport changes only)
#hrtest=48
# --- T7: right half copy only (scissor + viewport unchanged; the right
# half should show the left half's picture again)
#hrtest=80
#
# --- R1: picture window narrowed to 720 clocks (normal 480p width)
# Picture (or bars) on the left part of the screen -> the encoder
# blanks windows wider than 720 clocks.
#hr_hbs640=117
#
# --- R2: 525-line frame (480p line count, 30 frames/s, 240 lines shown)
# The monitor may not like 30 Hz. Picture or bars -> the encoder counts
# lines and blanks frames that are not 525 lines long.
#hr_psbodd=528
#hr_psbeven=528
#hr_nhlines=1050
#
# --- R3: R1 and R2 together
#hr_hbs640=117
#hr_psbodd=528
#hr_psbeven=528
#hr_nhlines=1050
# =====================================================================
#
